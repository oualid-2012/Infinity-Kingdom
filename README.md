# Infinity Kingdom Landing Page

Landing page for **Infinity Kingdom** - The MMO Strategy Game.

## 🌐 Live Preview
Once deployed on GitHub Pages, the site will be available at:
https://oualid-2012.github.io/Infinity-Kingdom/

## 🚀 How to Enable GitHub Pages
1. Go to your repository on GitHub: [Infinity-Kingdom](https://github.com/oualid-2012/Infinity-Kingdom)
2. Go to **Settings** > **Pages** (under Code and automation)
3. Under **Build and deployment**:
   - **Source**: Select **GitHub Actions** (the included workflow will deploy automatically)
   - *Or* select **Deploy from a branch**, choose `main` branch and `/ (root)` folder, then click **Save**.
